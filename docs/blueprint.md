# **App Name**: Tela Noturna

## Core Features:

- Black Screen Display: Render a full-screen, uninterrupted black display to create a focus or relaxation environment.

## Style Guidelines:

- Primary color: A deep, muted indigo (#22224D) to define subtle UI elements, evoking a sense of calm depth. This color would be used sparingly for any non-black elements that might appear.
- Background color: A very dark, almost black charcoal (#0B0A0F) filling the entire screen, serving as the main visual experience. This ensures the primary purpose of a 'black screen' is met while maintaining an analogous palette.
- Accent color: A soft, muted teal (#337E99) to provide occasional, non-intrusive highlights or interactive states if any subtle UI interactions were introduced later.
- Body and headline font: 'Inter' (sans-serif) for its neutral, clean, and objective aesthetic, maintaining absolute minimalism in any potential textual elements.
- Iconography: No explicit icons for the core 'black screen' function; should future, subtle UI elements be added, simple, ghost-like outline icons would be employed to maintain minimalism.
- Layout: The application's sole layout is a fullscreen, seamless black canvas, providing a pure, unadorned experience.
- Animation: A gentle, slow fade-in effect for the black screen upon application load, ensuring a soft and serene transition into the desired state of focus.
